# site

Public marketing page for the platform (Next.js, port 3001).

```bash
npx turbo run dev --filter=site
```

Environment variables (optional):

- `NEXT_PUBLIC_APP_NAME`: platform name (default `GymSuite`)
- `NEXT_PUBLIC_APP_URL`: dashboard URL that "Sign in" / "Get started" link to (default `http://localhost:3000`)
